# Timeblock settings

Copy to `~/.config/tools/timeblock.md` and make it yours. Changes show up in the open page straight away.

## Time zones

One line per zone, `- Name: Area/City`, in the order you want them. Use a zone name from
https://en.wikipedia.org/wiki/List_of_tz_database_time_zones. Add `(IC)` to the zone you work to as incident commander.

- London: Europe/London
- New York: America/New_York (IC)
- San Francisco: America/Los_Angeles
- Sydney: Australia/Sydney
